# shootingallday

Jomar's personal site: a futures trader who builds his own trading tools. Vite, React and Tailwind on the PX Brand design system, with PX's ticker tape, candlestick chart and order book on a simulated feed, and a live reshuffle demo.

```sh
pnpm install
pnpm dev
pnpm build   # static site in dist/
```

PX components come from the PX Brand registry (`components.json`); serve `PX Projects` on 127.0.0.1:8765 to add or refresh one.
